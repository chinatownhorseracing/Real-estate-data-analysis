# Real estate data analysis

Property sales data and a Jupyter notebook for real estate data analysis.

## Files

- `Real estate data analysis.ipynb`: analysis notebook.
- `2002-2018-property-sales-data.xlsx`: original property sales dataset.
- `Property sales cleaned dataset.xlsx`: cleaned dataset.
- `Property sales dataset cleaned sample.xlsx`: sample of the cleaned dataset.
- `Property sales description.xlsx`: descriptive statistics.
- `Property sales routine dispersion.xlsx`: dispersion statistics.
- `Property sales routine tendencies.xlsx`: central tendency statistics.
- `Property sales uncleaned first 5 records.xlsx`: first five uncleaned records.
